# 🟣 AI Chat App — Gemini & ChatGPT Integration

A smart chat application powered by **Google Gemini API** and **ChatGPT API (OpenAI)** to deliver real-time AI-based conversations. This project uses **TypeScript**, **JavaScript**, **HTML**, and **CSS**, along with **WebSockets** for multi-user chat and AI-powered responses.

---

## 🚀 Features

- ✅ Real-time user-to-user chat (WebSocket)
- ✅ AI Assistant replies using Gemini or ChatGPT
- ✅ Supports **Join Message** and **Chat Message**
- ✅ Clean and simple UI
- ✅ Fully customizable AI response system
- ✅ Easy to switch between Gemini and ChatGPT APIs

---

## 📌 Tech Stack

- **Frontend**: HTML, CSS, JavaScript (TypeScript)
- **Backend**: Node.js with WebSocket
- **AI Integration**:
  - Google **Gemini API** — [Gemini Docs](https://ai.google.dev/)
  - OpenAI **ChatGPT API** — [ChatGPT Docs](https://platform.openai.com/docs)
